# C# 45 Mini Projects

Bu repository, **C# ve WinForms öğrenme sürecimde geliştirdiğim 45 mini projeyi** içermektedir.
Projeler başlangıç seviyesinden orta seviyeye kadar ilerleyen bir yapıda hazırlanmıştır.

Amaç:

* C# programlama pratiği yapmak
* Algoritma becerilerini geliştirmek
* WinForms masaüstü uygulama geliştirmeyi öğrenmek
* GitHub üzerinde düzenli proje paylaşımı yapmak

## Kullanılan Teknolojiler

* C#
* .NET
* WinForms
* Visual Studio

## Amaç

Bu repo hem **öğrenme sürecimi belgelemek** hem de **C# masaüstü uygulamaları için bir proje arşivi oluşturmak** amacıyla hazırlanmıştır.

## Not

Projeler düzenli olarak güncellenerek repo genişletilecektir.
